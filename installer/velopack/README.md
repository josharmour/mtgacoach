# Managed Coach installations

Velopack owns the native launcher and updater. The launcher starts the bundled Python desktop, stages deltas, and waits for the GUI, engine, and speech worker to exit before applying a package. The existing match-completion checks authorize an automatic restart only when the target package declares the same runtime and bridge compatibility identifier. A larger change appears under Help for approval. Settings, credentials, and game history stay in their existing user directories.

Users choose **stable** for published GitHub releases or **master** for commits that pass the master test workflow and all native builds. Install once from the corresponding [stable feed](https://github.com/josharmour/mtgacoach/releases/tag/coach-stable-feed) or [master feed](https://github.com/josharmour/mtgacoach/releases/tag/coach-master-feed). Use Setup on Windows, the Mac package for the machine's architecture, or the AppImage on Linux. An existing Inno, pip, or Git installation needs this one-time migration. Close the old copy and use the new shortcut. A source checkout remains under Git control.

Release feeds are partitioned by lane, platform, and architecture. CI downloads the previous package before running vpk so it can build a delta. CI uploads all packages before updating the indexes. An offline check leaves the installed version available. The host logs update errors under the OS local application-data directory in mtgacoach/updates/<channel>/update.log.
