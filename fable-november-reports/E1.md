## Changes

- One central forced-selection gate covers direct model callers as well as the
  normal post-filter path, including mandatory pass, target, selection and group
  requests. Empty/cancel/implicit-pass/repeated-mode alternatives and validation
  failures abstain. Legal development remains legal.
- Reuse requires exact serialized menu semantics (except transport request ID)
  and snapshot (except transport game-state counter/timestamp), same turn/window
  and existing 30-second TTL. Same-size changed hands and changed costs no longer
  reuse stale answers. More conservative misses are acceptable.
- Planner certainty requires complete, unbounded, non-tactical evaluated lines
  for every offered option, same survival horizon, and value margin at least 5.
  Unknowns, lethal/survival warnings, stack, alternate-cost aliases, incomplete
  evaluation and implicit choices abstain. Pass mapping only main-two no-cast
  without pending land development. This is deliberately bounded, not a new rules
  engine.
- `guard_planner_certain` / `ARENAMCP_PLANNER_CERTAIN` defaults to **shadow** via
  existing dynamic guard-setting registration. No live setting changed. Shadow
  continues the model and logs proposed/model IDs, agreement and decision type;
  separate `on` mode skips it. Owner decides activation after evidence.
- `tools/e1_shadow_metrics.py` reports recorded baseline, singleton-menu audit,
  and real shadow agreement by decision type. It explicitly never labels an
  offline estimate as observed before/after savings.
