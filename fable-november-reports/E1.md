# E1 safety correction after CI rejection

The earlier broad singleton bypass is rejected and its claims below are historical.
This successor restores the pre-E1 action-only policy (including retaining model
reasoning for pass), with additional abstention for repeated-selection metadata.
Target, search, mode, group and other selection families retain their semantic
classifiers. Direct `_llm_decision_options` callers retain their requested model
reasoning. Rule 1's additional savings are NOT implemented or accepted.

Retained changes: conservative planner-certainty SHADOW instrumentation, stronger
answer identity, duplicate-safe metrics. Cache identity now normalizes missing
public-entry relay evidence and offered-action binding exactly as public entry
does, while preserving already-bound cost evidence. It does not drop changed
hand/mana/card/option inputs. No ON activation, restart, real-match agreement or
before/after savings claim. Full-suite and independent review still required.

The exact 34 failing CI tests plus E1/cache tests pass (69 tests). All prior
behavioral tests are unchanged; the existing guard-settings test only acknowledges
the new registered `planner_certain=shadow` default and diagnostic label. E1's own
new tests now explicitly preserve model calls instead of asserting unsafe skips.
