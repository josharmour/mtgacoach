# MTGA Coach 3.8.2

## Deck strategy and live decisions

- Coach can prepare the selected deck's playbook while Arena is idle. A cached playbook loads without a model call. Brawl playbooks now use the same main-deck and commander lists before and during a match.
- On the hosted model, the opening plan and routine updates ask for the next two plays and the condition that would change the line. Coach keeps a usable step on an uneventful turn. A lost card, a new threat or a lethal attack can justify a new plan.
- Tactical decisions can proceed while a background plan is being written. In one observed live update, Coach produced a validated defensive plan in 6.7 seconds. Timing depends on the board and server load.

## Combat and Autopilot

- Combat planning accounts for poison and mill wins in the attack search. Block selection reuses calculations shared by candidate assignments.
- Decision traces distinguish request time from submission time and exclude measurements from a previous decision. Recovery planning after a canceled request uses a bounded deadline.
- The ongoing Autopilot backlog includes regression coverage as well as behavior changes. Independent review and live qualification remain open on the backlog.

## Windows update

Download **mtgacoach-Setup.exe** from this release and install it over your current version. Existing settings and trial credentials are preserved by the installer. The Python wheel is also attached for package-based installs.
