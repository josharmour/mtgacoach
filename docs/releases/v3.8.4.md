# MTGA Coach 3.8.4

This release brings the tested master improvements to stable users on Windows x64, Apple Silicon Mac, and Linux x64.

- Chatterbox streams from the hosted speech service at api.mtgacoach.com, with delivery intensity that follows commentary events and style. Speech settings can be saved when server voices are unavailable.
- Screen capture setup is available when a feature needs it. Debug reports can still be saved without a screenshot when macOS has not authorized capture. Desktop startup avoids initializing microphone-related audio code unnecessarily.
- Mac and Windows Dev launchers use local Python environments with shared source for quicker iteration. Windows Dev starts Arena automatically and preserves an already running game or launcher.
- Recent Match recovery, empty-selection handling, and bridge safety fixes improve autoplay reliability. Compatible coaching updates continue to apply at safe match boundaries; runtime and bridge changes require approval.
- Packaged app, Python wheel, updater, and website labels use the release's actual version. Intel Mac packages are no longer produced.

Existing managed stable installations receive this update through Coach. Master users continue following the master channel. Dev users run their selected source checkout.
