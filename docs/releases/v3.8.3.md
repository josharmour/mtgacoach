# MTGA Coach 3.8.3

Coach now has Velopack distributions for Windows x64, Linux x64, and Apple Silicon and Intel Macs. Choose the stable distribution to follow published releases or the master distribution to follow tested master builds. An existing Inno, package or Git installation needs a one-time migration to the managed app. Coach keeps its existing per-user settings and credentials.

The managed app checks when you launch it, downloads a delta when available, and restarts between matches for compatible updates. A runtime or Arena bridge change waits for your approval under Help. The title bar shows the channel, package build, and Git commit.
