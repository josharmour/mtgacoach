# Master update: Autoplay selection and Mac reliability

This update fixes an Autoplay loop on Windows when Arena asks you to acknowledge a card without selecting it, such as a Herald's Horn look-only prompt. The bridge now preserves an explicit empty selection instead of submitting Arena's arbitrary-selection sentinel. The Windows bridge is version 0.7.3.

On Mac, match history uses accessible buttons to avoid the Qt 6.12.0 table-accessibility crash path. The native bridge no longer intercepts process-wide memory-fault signals, and validates readable object headers more carefully. This removes unsafe fault recovery; it does not establish the cause of every Arena crash. Managed Mac packages now include the corrected native bridge (0.3.3).

Autoplay also treats idle menus and partially refreshed hands more carefully and rejects tactical actions that would cause lethal self-damage. Offline thinking-budget replay tools and opt-in selective thinking are included for development; selective thinking remains disabled by default pending latency qualification.

Recent master builds also include rank and match-history display, post-match queue fixes, and managed updates for Windows x64, Linux x64, Apple Silicon Mac, and Intel Mac.

## Installing

Use the [master feed](https://github.com/josharmour/mtgacoach/releases/tag/coach-master-feed) for the latest tested build. The [stable feed](https://github.com/josharmour/mtgacoach/releases/tag/coach-stable-feed) follows named releases and does not automatically receive each master change.

Existing managed master installations check for updates on launch. Finish your match, close Arena, click **Update** in Coach, and approve the restart. Launch Arena through Coach afterward so the corrected bridge is loaded. Older source, pip, or Inno installations need a one-time managed install: Windows Setup EXE, the Mac package for your processor, or the executable Linux AppImage. Settings, credentials, and local history use the same per-user locations. See [the installation and update guide](../../RELEASE.md).

## Validation

- Full Python suite: 9,167 passed, 17 skipped on the development Mac.
- Ruff lint and formatting checks passed.
- Windows bridge rebuilt against Arena assemblies; source/binary provenance verified. The production selection handler passed empty, single, multiple, missing-input and Search cases using `scripts/check_bridge_selection.py` with .NET 10 and Arena's Newtonsoft.Json assembly.
- Native Mac harness passed 15 cases on both Apple Silicon and Intel under Rosetta, including protected memory, GC cleanup, and main/worker-thread fault routing.
- Mac history passed 50 refreshes and 1,000 accessible selections using the installed Qt 6.12.0 runtime in an isolated offscreen process.

Publication still requires the PR checks, merged-commit checks, and all four managed package builds and launch checks. The master feed identifies the commit and version actually available for download.
