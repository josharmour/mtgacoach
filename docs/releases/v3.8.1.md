# MTGA Coach 3.8.1

A small follow-up to 3.8.0. It ships the fixes that landed after the 3.8.0 tag
was cut, so the installer and the wheel now match master.

## Speech

- Coaching advice is spoken in every speech mode. Advice used to be emitted as an
  uncategorized speak request, which the desktop treated as workflow and dropped
  in Announcer mode — a reported line ("Put both Emrakuls onto the battlefield…")
  appeared in the feed but was never heard. Advice now has its own speech
  category between urgent alerts and workflow, so it plays in Coach and Announcer
  modes alike, stays interruptible by urgent gameplay, and survives a mode change
  while it is queued.
- Suppressed speech is no longer logged as spoken, and markdown advice plus its
  stripped narration copy no longer appear twice in the feed.
- Autopilot local narration stays routine (still gated by mode); threat-combo
  lines stay urgent.

## Trial and license state

- The desktop app shows expired-trial and license-key state instead of a generic
  failure, including the startup health line and the Coach sidebar.
- Verified trial users receive one expiration email when their trial ends. The
  claim is recorded per trial, sent from the subscription check, the trial
  endpoint and a five-minute background sweep, and released if SMTP delivery
  fails. Trials without a verified email are not eligible.

## Tests

- The burn-heavy latency test no longer depends on the wall clock: it lifts the
  hard cap so only the deterministic work budget can end the search.
- A leaked background plan refresh can no longer fail the next test; the suite
  waits for the strategic lane between tests and names the holder if it never
  finishes.

## Installer

The Windows installer keeps the 3.8.0 packaging model: official signed CPython
3.11 under `{app}\runtime` with a non-editable wheel install of `arenamcp[full]`,
no build-machine source path, and no copied virtual environment. CI relocates the
staged runtime to a path containing spaces, silently installs it, and verifies
the installed copy with the checkout source hidden.

## Known limits

- Windows autopilot still requires the BepInEx bridge; Mac autoplay remains
  bridge-only.
- The shared NAS checkout is not reachable from the Windows VM (`Z:` mapping),
  so Windows verification uses installed copies rather than a live source tree.
