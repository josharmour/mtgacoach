# MTGA Coach 3.8.0

This release brings ArenaOnAir into the regular Coach and consolidates completed
work through November 1, 2026 at 07:32 UTC. It includes earlier unreleased changes
since 3.7.0 as well as the overnight repair batches.

## Speech and commentary

- Simple speech on/off, Coach advice versus Announcers, Kokoro versus Chatterbox,
  Server Chatterbox selection, voice previews, and a 1.5× default playback speed.
- Two distinct announcer roles and four styles: Classic radio booth, Esports hype
  desk, Test-match understatement, and Pro Tour analysts (technical).
- Retry interrupted opening delivery within bounded budgets; retain useful recent
  outcome recaps across unrelated phase changes; reuse observed-play explanations.
- Natural player-name pronunciation and better speaker/queue ownership. Speech
  work remains subordinate to urgent gameplay.

## Automation and gameplay

- Fresh native Mac bridge handshakes, incomplete-hand safeguards, reconnect and
  stale-request handling, and far-left Recent Match replay using its deck/format.
- Selection fixes cover numeric choices, basic land types, and SelectN-to-scry
  transitions. Result recording retains the correct match/player identity.
- Bounded improvements to legend-rule projections, combat damage and protection,
  attack taxes, poison/library loss, returning enchantments, mana reservations,
  and legal-plan/action consistency.
- Commander forecasts respect known outside-hand casting restrictions. Replacement
  prompts distinguish hand/library recovery from command-zone access and known tax.
- Free-equip mana relay context uses current targets and Arena-quoted payoff costs;
  protection explanations distinguish a spell on the stack from a permanent.
- Draft explanations and alternative comparisons are clearer. Traditional Limited
  sideboarding uses request identity and registered-pool constraints.

## Validation and qualifications

The integration used focused offline regressions and recorded-event fixtures,
including a 1,283-pass combined run whose failures were investigated separately.
Release-gate results and installer artifacts are linked from the GitHub release;
local affected runs alone are not described as full-suite or live certification.
The release also repairs a known named-card shorthand validation gap that surfaced
during the combined checks.

The planner is not a complete rules engine. General trigger chains, same-turn
removal-then-commander-cast search, arbitrary activation/replacement effects, and
full horizon-wide sequence ranking remain incomplete. Several retained cases use
explicitly reconstructed minimal states rather than original complete snapshots.
CPU timing tests have varied with machine conditions; no timing limit was relaxed,
and idle-machine performance is not newly certified. Constructed sideboarding
remains manual. Local/server Chatterbox availability and audio output depend on the
installed runtime; Windows and native Mac live qualification remain distinct.

Malformed-response diagnostics are opt-in, bounded and redacted. The earlier raw
capture patch is deliberately superseded, not reintroduced in this release.

## Release preparation follow-ups

Three separately reviewed fixes requested after the overnight cutoff are included:
automatic bridge, match-review, and vision diagnostics stay local; manual public
GitHub filing shows the destination and contents and requires confirmation. Cancelling
or reusing a consumed confirmation cannot publish a report. Windows startup avoids
re-probing the Python interpreter already running Coach, and local Chatterbox discovery
recognizes Windows virtual-environment paths. These changes passed 126 combined
affected tests; total startup latency and actual Chatterbox setup remain separately
qualified concerns.

## Updating

Close Coach before updating its editable source or installed runtime. Keep any
active Arena match intact; update the native bridge only at a safe Arena restart.
Use the release's Windows installer or Python wheel as appropriate. The experimental
native Mac bridge must match Coach; it does not alter operating-system lock settings.
